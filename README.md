# Forecasting Room Occupancy for HVAC Scheduling

**MMA3001 Numerical Methods and Machine Learning, Monash University (2026)**
**Author:** Raj Mahida
**Dataset:** Dataset 2, Monash Smart Infrastructure Occupancy and Environmental Data

> 🚧 **Work in progress.** Done: data cleaning and audit (notebook 01), baseline and timetable (notebook 02), machine-learning model with final test (notebook 03). Next: robustness checks.

## Project question

*Can hourly room occupancy be forecast from time and calendar patterns, so that
a building's heating, ventilation and air-conditioning (HVAC) system only
conditions spaces when people are expected?*

- **Engineering context:** HVAC is one of the largest energy uses in buildings.
  Running it on a fixed timetable heats and cools empty rooms. An occupancy
  forecast lets the system pre-condition a space only when it will be used.
- **Inputs:** time-stamped occupancy-sensor readings (status and headcount)
  for 5 spaces, Nov 2023 – Apr 2026.
- **Output:** predicted average headcount for each space, for each hour.
- **Baseline method:** typical profile, i.e. the historical average for each
  hour of each weekday.
- **Main method:** a day-ahead forecast made at midnight with gradient-boosted
  decision trees (scikit-learn `HistGradientBoostingRegressor`), using the
  calendar, Monash semester weeks and recent occupancy.
- **Validation:** chronological split: train before 2025, tune on 2025,
  test once on Jan–Apr 2026.

## Results so far (2026 test period, never used for training or tuning)

| Approach | MAE (people) | HVAC decision correct | Wasted hours | Discomfort hours |
|---|---|---|---|---|
| Fixed timetable, 8am–8pm weekdays | – | 76.3% | 1,016 | 681 |
| Profile baseline | 0.678 | 74.7% | 1,259 | 549 |
| **Gradient boosting (ML)** | **0.581** | **79.2%** | **836** | 651 |

Full tables are in `reports/results/`, and the working is in `notebooks/03_ml_model.ipynb`.

## How to run

```bash
# 1. Get a copy of the repository
git clone https://github.com/rajmahida186-debug/mma3001-occupancy-forecasting.git
cd mma3001-occupancy-forecasting

# 2. Install the required Python packages and this project (Python 3.10+)
pip install -r requirements.txt

# 3. Run the tests and generate the HTML test report
pytest --html=reports/test_report/report.html --self-contained-html

# 4. Open the notebooks (they use the small files already in data/processed/)
jupyter notebook notebooks/

# 5. (Optional) Rebuild data/processed/ from the raw Monash files
#    Place the raw CSVs in data/raw/ first (see data/README.md). Takes ~2 minutes.
python -m occupancy.pipeline

# 6. Generate the HTML code documentation
pdoc src/occupancy -o docs
```
