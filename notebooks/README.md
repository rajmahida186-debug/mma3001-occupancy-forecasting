# Notebooks

Run these in order. Each notebook is the "story" of one stage of the project,
and calls the reusable functions in `src/occupancy/`.

| Notebook | Stage | Status |
|---|---|---|
| `01_data_audit.ipynb` | Explore the raw data and document quality problems | Planned |
| `02_cleaning_and_features.ipynb` | Clean the data and build model inputs | Planned |
| `03_baseline_model.ipynb` | Typical-profile baseline forecast | Planned |
| `04_ml_model.ipynb` | Machine-learning forecast | Planned |
| `05_validation_and_comparison.ipynb` | Test on unseen data, compare models, sensitivity and optimisation | Planned |
